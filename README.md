# Networking Interview Preparation

Computer networking for software and DevOps interviews, from "what is a network" to routing, TCP, DNS, TLS, security, data center design and Linux networking. Each chapter is a short note in simple language.

## How to use this repo

1. Read the folders in order. Each one builds on the one before it.
2. Do not skip `04-ip-addressing`: subnetting comes up in almost every networking round, so practice it until it is fast.
3. For a software role, the highest-value folders are `02-network-models`, `06-transport-layer` and `07-application-protocols`.
4. Before an interview, reread `02-network-models/05-what-happens-when-you-open-a-website.md`. It ties DNS, TCP, TLS and HTTP together in one story.
